Today I decided to start showing my technical work through GitHub.

I learn best by doing, so I found a course that walks through how to build different projects and publish them to GitHub using Pages. Instead of waiting until I feel “technical enough” to have a GitHub profile, I’m figuring things out as I go, step by step.

Right now, that means learning more about HTML, CSS, JavaScript, repositories, and how all of these pieces actually work together.

I’m especially interested in what happens when I combine the business strategy and systems thinking I already know with stronger technical skills.

No big declaration of where this is going yet. Just documenting the process of learning, building, and seeing what I can make.
